# What is IELTS? — curriculum map

LEVEL 2 (IELTS Basics), module 1. The test itself: versions, format, delivery,
Band Scores, marking and requirements. Every fact in the lessons matches the
checked IELTS facts Mino already uses (`lib/ai/server/mino/knowledge/ielts.ts`).
Fees, test dates, result times, retakes and institution requirements change and
differ by test centre, so the lessons never state them: they send the student to
the official IELTS / test centre website or the organisation's official page.

**Lesson flow (v2):** hook → discover → concept (with the common mix-up) →
examples → IELTS in Reading, Listening, Writing and Speaking → Common Mistake Lab
→ option practice (every wrong option explained) → free recall → error correction
→ mini challenge → a personal paragraph Mino checks (facts first) → summary →
spaced review.
