# Understanding IELTS Listening — curriculum map

LEVEL 2 (IELTS Basics), module 2. How the Listening test works and the skills
each part needs. Facts match `lib/ai/server/mino/knowledge/ielts.ts` (4 parts,
40 questions, about 30 minutes, heard once, answers in order, word limits,
spelling, "Choose TWO" marking). Practice uses short written transcripts
("You hear: …"), so every question works without audio; timed audio practice
belongs to the Listening tests, which are still planned.

| 1 | How Listening works | `ls-1` | `ls-format` | parts, questions, timing, heard once, order, preview time |
| 2 | Part 1 | `ls-2` | `ls-part1` | spelled names, numbers ("double", -teen / -ty), corrections |
